# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- The entry is relevant to content marketing: a tool, a platform, a guide, a book or a community that helps a business plan, create or distribute content.
- Search previous suggestions before making a new one; it may be a duplicate.
- Use the format `- [Name](link) - Description.` with a short, factual description ending in a period.
- Add the entry to the bottom of the most relevant section, or propose a new section if none fits.
- Links must work, use `https://` where available, and carry no affiliate, referral or tracking parameters.
- One suggestion per pull request, with a useful title.
- If you are affiliated with the tool or resource, say so in the pull request. Affiliation is fine; hiding it is not.
- No marketing copy: describe what the thing does, not why it is great.

Thank you for your suggestions.
